# SQL Placement Prep

Structured SQL/MySQL practice for placement interviews — DDL, DML, joins, 
subqueries, and query-solving exercises for TCS, Infosys, Wipro, and other 
IT companies.

## 📚 Roadmap

- DBMS Basics
- SQL Command Types (DDL, DML, DQL, DCL, TCL)
- Creating & Managing Databases (CREATE, ALTER, DROP, TRUNCATE)
- Keys & Constraints
- INSERT, UPDATE, DELETE
- SELECT & WHERE (filtering, LIKE, IN, BETWEEN, ORDER BY)
- Aggregate Functions & GROUP BY / HAVING
- JOINs (INNER, LEFT, RIGHT, SELF)
- Subqueries
- Normalization (1NF, 2NF, 3NF, BCNF)
- Transactions & ACID
- LeetCode SQL Practice

## 🛠️ Tools
- MySQL 8
- [DB Fiddle](https://www.db-fiddle.com/) for running queries

## 📂 Structure
Each folder contains `.sql` files with the problem/topic as a comment, 
followed by the query.
